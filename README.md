
## Ветка DEV: тестовый деплой на Render (FREE PLAN)

В ветке **dev** всё настроено под **тестовый** разворот на **бесплатной** версии Render.

- **БД: SQLite.** PostgreSQL не используется: на free невозможно подключить Postgres. Данные не могут не сохраняться между перезапусками/деплоями — этого достаточно для теста.
- **Суперпользователь (админка)** создаётся автоматически при деплое: в Render в **Environment** задается **DJANGO_SUPERUSER_EMAIL** и **DJANGO_SUPERUSER_PASSWORD** — при старте контейнера выполнится `createsuperuser --noinput`. Shell на бесплатном плане недоступен, поэтому создание админа только так.
- **Города** подгружаются из короткого списка в JSON (`carpooling/data/cities_seed.json`) командой `seed_cities` при старте — только для тестового поиска, полный импорт (geonames) не используется.
